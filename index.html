Module 5 Custom Theme

Jenny's Minnesota Favorites continues to grow from the website created in previous course modules. Module 5 introduces a custom jQuery Mobile theme created with ThemeRoller.

The custom Minnesota-inspired theme includes all three required swatches. Swatch A uses forest green and cream, Swatch B uses lake blue and light blue-green, and Swatch C uses gold and cream.
