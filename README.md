# Jenny's Minnesota Favorites

## Website Summary

Jenny's Minnesota Favorites is a mobile-friendly website application designed to highlight some of my favorite places and outdoor activities in Minnesota. The site focuses on lakes, trails, peaceful places, and outdoor recreation while allowing users to explore destinations, plan a visit, and create a personalized list of favorites.

The application was developed throughout Modules 1–6 of the Mobile Application Development course. It incorporates HTML, CSS, JavaScript, jQuery Mobile, responsive design, forms, lists, panels, grids, Web Storage, and a custom ThemeRoller theme.

## Website Structure / Site Map

Home (index.html)
- Favorite Places (places.html)
- Outdoor Activities (activities.html)
- Plan a Visit (planner.html)
- My Favorites (favorites.html)

All major pages provide navigation that allows the user to move throughout the application.

## Home Page - index.html

The Home page introduces Jenny's Minnesota Favorites and provides the main navigation for the application. It also displays the custom Minnesota-inspired ThemeRoller design.

### Buttons and User Actions

**Menu**
- Action: The user selects the Menu button.
- Result: The navigation panel opens and provides additional navigation options.

**Home**
- Action: The user selects Home.
- Result: The user is returned to the main Home page.

**Favorite Places**
- Action: The user selects Favorite Places.
- Result: The Favorite Places page opens.

**Outdoor Activities**
- Action: The user selects Outdoor Activities.
- Result: The Outdoor Activities page opens.

**Plan a Visit**
- Action: The user selects Plan a Visit.
- Result: The trip-planning page opens so the user can enter information about a planned Minnesota visit.

**My Favorites**
- Action: The user selects My Favorites.
- Result: The saved favorites page opens.

**View Places**
- Action: The user selects View Places.
- Result: The Favorite Places page opens.

**View Activities**
- Action: The user selects View Activities.
- Result: The Outdoor Activities page opens.

**Manage Favorites / Create My Favorites List**
- Action: The user selects the favorites option.
- Result: The My Favorites page opens, where favorite items can be entered and stored.

## Favorite Places Page - places.html

The Favorite Places page provides information about selected Minnesota destinations and allows users to browse the places included in the application.

### Buttons and User Actions

**Navigation Buttons**
- Action: The user selects one of the navigation options.
- Result: The corresponding page of the application opens.

**Back**
- Action: The user selects the Back button when available.
- Result: The application returns the user to the previous page.

**Filtered List**
- Action: The user enters text into the filter field.
- Result: The displayed list is narrowed to items matching the user's search.

## Outdoor Activities Page - activities.html

The Outdoor Activities page highlights outdoor recreation and activities that can be enjoyed in Minnesota.

### Buttons and User Actions

**Navigation Buttons**
- Action: The user selects a navigation option.
- Result: The corresponding page opens.

**Back**
- Action: The user selects the Back button when available.
- Result: The user returns to the previous page.

**Filtered List**
- Action: The user types into the filter field.

## Plan a Visit Page - planner.html

The Plan a Visit page contains a form that allows users to enter information for a planned Minnesota trip.

### Buttons and User Actions

**Form Fields**
- Action: The user enters the requested trip information.
- Result: The information is prepared to be saved using the application's Web Storage functionality.

**Save Plan**
- Action: The user completes the form and selects the save/submit option.
- Result: The visit information is saved in the browser using Web Storage.

**Navigation / Back**
- Action: The user selects a navigation or Back button.
- Result: The appropriate application page opens.

## My Favorites Page - favorites.html

The My Favorites page allows users to create and maintain a personalized list of Minnesota favorites.

### Buttons and User Actions

**Add to Favorites**
- Action: The user enters a favorite item and selects the button to add it.
- Result: The item is stored using Web Storage and displayed in the favorites list.

**Remove/Clear Favorites**
- Action: The user selects the available option to remove or clear saved favorites.
- Result: The selected stored favorite information is removed from the browser.

**Navigation / Back**
- Action: The user selects a navigation or Back option.
- Result: The corresponding application page opens.
